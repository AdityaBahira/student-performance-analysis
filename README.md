# 📊 Student Performance Analysis  
### Data Science / Data Analysis with Python – Task 1

---

## 📌 Project Overview
This project is completed as part of **Task 1** of the *Data Science / Data Analysis with Python Internship*.  
The goal of this task is to explore and analyze the **Student Performance Dataset** using Python by following the complete data science workflow:

**Load → Clean → Analyze → Visualize → Conclude**

---

## 📂 Dataset Description
The dataset contains information related to students’ academic performance, demographics, family background, and lifestyle habits.

Key attributes include:
- Study time
- Gender
- Absences
- Alcohol consumption
- Period-wise grades (G1, G2, G3)

The final grade (**G3**) is used as the primary performance indicator.

---

## 📎 Dataset Source & Citation
The dataset is sourced from the **UCI Machine Learning Repository**, a widely used and trusted academic dataset provider.

**Citation:**

> Cortez, P., & Silva, A. (2008).  
> *Using Data Mining to Predict Secondary School Student Performance*.

## 🔍 Tasks Performed

### 1️⃣ Data Loading & Cleaning
- Loaded the dataset using Pandas
- Checked for missing values
- Removed duplicate records
- Inspected dataset shape and data types

### 2️⃣ Exploratory Data Analysis
- Calculated the average final grade (G3)
- Counted students scoring above 15
- Analyzed correlation between study time and performance
- Compared average performance across genders

### 3️⃣ Data Visualization
- Histogram of final grades
- Scatter plot: study time vs final grade
- Bar chart: male vs female average score

### 4️⃣ Documentation
- Used Markdown cells in Jupyter Notebook
- Clearly explained each step of the analysis

---

## 📊 Key Insights
- Most students fall within the average grade range.
- Only a limited number of students score above 15.
- Study time has a weak positive correlation with academic performance.
- Gender-based differences in performance are minimal.
- Student performance is influenced by multiple factors beyond study time alone.
